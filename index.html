ROM 파일 선택

본인이 가진 포켓몬 하트골드 .nds 파일을 선택하세요.
파일은 서버로 전송되지 않고 이 브라우저에만 보관됩니다.

조작키

WASD이동
ShiftB 달리기 / 취소
JA 확인 / 대화
LX 메뉴
IY 등록 아이템
EnterSTART
BackspaceSELECT
QEL / R

터치 스크린

마우스 클릭/드래그아래 화면 터치

저장

F5퀵 세이브
F9퀵 로드
Space빨리감기(누르는 동안)

게임 내 저장(리포트)은 브라우저에 자동 보관됩니다. 키는 톱니바퀴 메뉴 → Control Settings에서 바꿀 수 있어요.
